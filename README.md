# 心情播放器 (Mood Music Player)

一個結合音樂播放與心情日記的現代化 Web 應用程式，採用 Nuxt 4 和 Vue 3 開發。

## 功能特色

### 音樂播放
- 6 種心情選擇：快樂、悲傷、活力、放鬆、浪漫、專注
- 完整播放控制：播放/暫停、上一首/下一首、進度條拖曳
- 音量控制：可調整音量大小
- 播放清單：點擊歌曲切換播放

### 心情日記
- 日曆視圖：直觀的日期選擇介面
- 寫日記：記錄每天的心情和文字
- 編輯日記：修改已儲存的內容
- 刪除日記：移除不需要的記錄
- 心情標籤：不同心情有對應的顏色標記
- 日期標記：有寫日記的日期會在日曆上標示

## 技術棧

- **前端框架**：Nuxt 4 + Vue 3
- **狀態管理**：Pinia
- **樣式設計**：Tailwind CSS + 自訂 CSS
- **後端**：Nuxt Server API (Node.js)
- **資料庫**：MySQL
- **語言**：TypeScript
- **音頻 API**：HTML5 Audio API
