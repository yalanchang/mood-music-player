# 心情播放器 (Mood Music Player)

一個根據心情推薦音樂的現代化 Web 應用程式，採用 Nuxt 4 和 Vue 3 開發。

## 功能特色

- 6 種心情選擇：快樂、悲傷、活力、放鬆、浪漫、專注
- 音樂播放控制：播放/暫停、上一首/下一首、進度條拖曳
- 搜尋功能：在播放清單中搜尋歌曲
- 音量控制：可調整音量大小
- 響應式設計：支援手機、平板、電腦
- 精美 UI：玻璃態設計、圓形按鈕、漸層背景

## 技術棧

- 前端框架：Nuxt 4 + Vue 3
- 狀態管理：Pinia
- 樣式設計：Tailwind CSS + 自訂 CSS
- 語言：TypeScript
- 音頻 API：HTML5 Audio API
